# ECC 新功能开发速查卡

## 推荐流程

`planner -> tdd-guide -> code-reviewer -> security-reviewer`

## 一键 Prompt（10 条）

```text
新增功能：{功能名}，按 ECC 标准流程完整执行并输出每阶段结果。
```

```text
先做实现规划，不要急着写代码：请输出模块拆分、接口设计、风险点。
```

```text
请先写失败测试再实现 {功能}，并给出关键边界测试点。
```

```text
在不破坏现有行为前提下实现 {功能}，并说明兼容策略。
```

```text
请按“最小可用版本 -> 增强版本”两阶段实现 {功能}。
```

```text
为 {功能} 设计 API：请求参数、响应结构、错误码、分页方案。
```

```text
实现 {功能} 后请生成回归测试清单，覆盖关键主流程。
```

```text
请对新功能改动做代码评审并指出高风险点。
```

```text
请对 {功能模块} 做安全审查并给上线建议。
```

```text
最终输出：实现摘要、修改文件、测试结果、风险与后续优化建议。
```

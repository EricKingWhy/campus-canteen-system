# ECC 接口与数据库速查卡

## 一键 Prompt（10 条）

```text
设计接口：{接口名}，请输出请求参数、响应体、错误码、分页策略。
```

```text
对 {接口} 补齐输入校验和错误处理，并给出异常场景测试。
```

```text
请为 {接口} 生成契约测试建议，确保前后端字段一致。
```

```text
请设计 {业务} 的数据库表结构，包含索引、唯一约束、审计字段。
```

```text
请评审这条 SQL 的性能和正确性：{SQL 语句}。
```

```text
请给出 {数据变更} 的迁移脚本策略和回滚脚本策略。
```

```text
请检查 {事务逻辑} 是否存在一致性问题并给修复建议。
```

```text
请定位 {查询慢} 问题并给最小风险优化方案。
```

```text
请帮我生成接口联调清单：成功、失败、空数据、权限不足四类场景。
```

```text
请输出接口上线前检查项：鉴权、限流、监控、告警、回滚。
```

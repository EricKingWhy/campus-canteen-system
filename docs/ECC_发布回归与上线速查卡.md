# ECC 发布回归与上线速查卡

## 一键 Prompt（10 条）

```text
请为本次改动生成回归测试清单，按高风险优先级排序。
```

```text
请给我上线检查清单：配置、依赖、数据库、缓存、监控、告警、回滚。
```

```text
请检查本次发布的潜在回归点，重点关注 {核心流程}。
```

```text
请输出这次发布说明，给产品和测试都能直接看懂的版本。
```

```text
请生成灰度发布策略：灰度范围、观察指标、放量条件、回退条件。
```

```text
请给出“是否可上线”的结论和阻塞项，按严重级别列出。
```

```text
请输出回滚预案：触发条件、回滚步骤、回滚后验证项。
```

```text
请帮我设计上线后 24 小时监控计划：指标、阈值、告警接收人。
```

```text
请给本次发布做风险分级（高/中/低），并给应对动作。
```

```text
请生成事故复盘模板，方便出现问题后快速复盘。
```

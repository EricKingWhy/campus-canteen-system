## 🐛 核心 Bug 修复 (Critical Fixes)

### 1. 雪花算法 ID 精度丢失问题
| 项目 | 内容 |
|---|---|
| **现象** | 前端查询订单详情报 404，数据库 ID 与前端 ID 不一致 |
| **原因** | JS `Number` 类型使用 64 位浮点表示，无法精确存储 Java `Long` (19位)，导致后几位被截断 |
| **方案** | 扩展 Spring MVC 消息转换器 (`WebMvcConfiguration.java`)，将 `Long` 类型统一序列化为 `String` 传输 |
| **涉及文件** | `WebMvcConfiguration.java`, `OrderController.java` |

### 2. 后端空指针异常 (NPE)
| 项目 | 内容 |
|---|---|
| **现象** | 进入订单详情页白屏，后端报 `NullPointerException` |
| **原因** | 打包订单无 `addressBookId`，代码仍尝试查询地址簿导致空指针 |
| **方案** | 重构 `OrderServiceImpl.details()`，增加防御性判空，打包单直接赋值取餐地点 |
| **涉及文件** | `OrderServiceImpl.java` |

### 3. 管理端接单溢出报错
| 项目 | 内容 |
|---|---|
| **现象** | 点击"接单"报 `HttpMessageNotReadableException: Overflow` |
| **原因** | DTO 中 `id` 定义为 `Integer`，无法接收 19 位 Long 类型订单号 |
| **方案** | 将所有订单操作 DTO 的 `id` 类型修正为 `Long` |
| **涉及文件** | `OrderConfirmDTO.java`, `OrderRejectionDTO.java`, `OrderCancelDTO.java`, `admin/OrderController.java` |

### 4. JSON 时间格式解析失败
| 项目 | 内容 |
|---|---|
| **现象** | 菜单加载失败，控制台报 `InvalidDefinitionException: not supported LocalDateTime` |
| **原因** | 自定义 ObjectMapper 覆盖了默认配置，丢失了 JavaTimeModule |
| **方案** | 注册 `JavaTimeModule` 并禁用时间戳格式输出 |
| **涉及文件** | `WebMvcConfiguration.java` |

### 5. 前端参数名不匹配
| 项目 | 内容 |
|---|---|
| **现象** | 从历史订单跳转详情页，ID 获取为空 |
| **原因** | history.vue 传 `orderId`，orderDetail.vue 只接收 `id` |
| **方案** | 兼容两种参数名 `options?.id || options?.orderId` |
| **涉及文件** | `orderDetail.vue`, `history.vue` |

## ✨ 新增功能模块 (New Features)

### 1. 收银台流程 (Cashier Page)

**新增页面**: `pages/pay/pay.vue`

**功能特性**:
- 支付金额居中大字展示
- 支付方式单选：微信支付 / 线下支付(到付)
- AI 生成专属支付图标
- 确认支付按钮触发后端状态更新

**流程链路**:
```
提交订单(submit.vue) → 收银台(pay.vue) → 支付成功(success.vue)
       ↓                    ↓                    ↓
   创建订单             调用 payment API       显示取餐号
   状态=待付款           状态→待接单            跳转详情
```

### 2. 订单详情页闭环 (Order Detail)

**全栈数据绑定**:
- ✅ 动态取餐号（A/B前缀 + 订单号后5位）
- ✅ 楼层显示（堂食=一楼，打包=二楼）
- ✅ 备注、餐具份数从数据库加载
- ✅ 订单菜品列表含图片

**双端取消逻辑**:
- 用户端：待付款/待接单状态可取消
- 管理端：全状态可取消（带原因选择）
- 状态同步：`onShow` 生命周期自动刷新

### 3. 实时状态同步

**实现方式**: 在 `history.vue` 和 `orderDetail.vue` 中添加 `onShow` 生命周期钩子

**效果**:
- 管理员后台取消订单 → 用户小程序刷新后显示"已取消"
- 支付成功后刷新 → 订单状态变为"待接单"

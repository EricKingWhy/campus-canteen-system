# 校园食堂智能推荐与餐费分析系统 - v1.0.0 核心里程碑版本
**Author**: 王浩宇
**Date**: 2026-03-03

## 🌟 核心功能特性 (Features)
* **智能健康画像模块**: 
  - 引入完整的个人健康档案系统，前端基于 Mifflin-St Jeor 公式实时计算 BMI、BMR 与 TDEE（每日总热量消耗）。
  - 支持动态录入用户的健康目标（增肌/减脂/维持）、饮食偏好及忌口/过敏源。
* **“智选6道菜”启发式推荐引擎 (核心算法)**: 
  - 摒弃了传统的随机或单纯销量推荐，重构为 **4层规则漏斗推荐模型**。
  - **第1层 (冷启动兜底)**：无画像用户智能展示全校热销榜单。
  - **第2层 (时间场景感知)**：根据当前系统时间自动匹配早/午/晚分类。
  - **第3层 (健康与忌口红线)**：严格计算 `TDEE 缺口`，拦截热量超标菜品，利用 `NOT LIKE` 阻断用户过敏源。
  - **第4层 (缺啥补啥动态排序)**：基于当日宏量营养素摄入情况进行加权动态排序（如蛋白质不足则 `ORDER BY protein DESC`）。
* **全栈数据大屏与管理台 (Admin Dashboard)**:
  - 新增“用户管理”模块，全面打通用户画像的数据沉淀。
  - 引入 ECharts 数据可视化，实现“餐费趋势分析”与“营养结构占比分析”，形成完整的闭环健康看板。

## 🛠️ 重构与脱敏 (Refactoring & Desensitization)
* **品牌重塑**: 完成全站代码级别脱敏，将原开源脚手架（苍穹/寒夜）的相关字眼、Logo 彻底剥离，全面重构为定制化B端管理系统UI，并重构极简暖色调登录页。
* **数据类型升级**: 解决前端 JS 精度丢失 (Long Precision Loss) 问题，统一升级实体与传输类的 ID 类型为 Long，并配置 Jackson 全局序列化方案。

## 🐛 关键缺陷修复 (Bug Fixes)
* **全链路模糊搜索重构**: 拆除 `/user/dish/list` 接口存在的 Redis 缓存刺客与前端 `categoryId` 参数污染，真正实现无死角的全局模糊搜索。
* **数据完整性兜底**: 修复员工管理模块实体属性不匹配及 `id_number` 字段约束冲突问题。
* **(2026-03-04) 多端数据闭环与聚合修复**: 修复前端 `my.vue` 数据大屏与后端的联动中断问题（接驳 `authentication` 头与修正 `code` 校验逻辑，增加属性 Fallback 映射），并在 `WebMvcConfiguration` 补齐 `/analysis/**` 路径的 Token 拦截白名单。同时，扩展后端 `OrderVO` 和 `OrderServiceImpl`，实现了订单历史详情中真实菜品份数 (`totalNum`) 的聚合计算与准确下发。

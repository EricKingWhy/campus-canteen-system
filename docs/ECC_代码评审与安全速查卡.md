# ECC 代码评审与安全速查卡

## 评审核心关注点

1. 逻辑 bug 与行为回归
2. 缺失测试与边界条件
3. 安全风险（鉴权、注入、泄露）
4. 可维护性（复杂度、可读性、耦合）

## 一键 Prompt（10 条）

```text
请 review 当前改动，按严重级别输出问题并给修复优先级。
```

```text
重点检查行为回归：这次改动是否会影响 {关键流程}。
```

```text
请找出缺失测试点并给最小测试补充方案。
```

```text
请从边界条件视角审查 {模块}，重点看空值、极值、并发、超时。
```

```text
对 {接口} 做安全审查：输入校验、鉴权、SQL 注入、XSS、错误泄露。
```

```text
检查是否存在硬编码密钥、token、密码或敏感配置。
```

```text
请输出“可上线/不可上线”结论和阻塞项。
```

```text
请给本次改动的安全加固建议，按收益/成本排序。
```

```text
对数据库相关改动做风险审查：事务一致性、索引、锁竞争、回滚策略。
```

```text
请生成一份 PR 审查摘要，面向团队可直接阅读。
```

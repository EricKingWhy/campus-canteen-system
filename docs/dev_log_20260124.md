## 三、Bug 修复列表

### Bug 1: Unknown column 'allergies' 导致保存失败
- **现象**：信息设置页保存时报 `SQLSyntaxErrorException: Unknown column 'allergies'`
- **根因**：`User.java` 实体声明了 `allergies` 字段，但数据库无此列
- **修复**：从 `User.java` 移除 `allergies` 字段（使用 `avoidTags` 替代）
- **验证**：保存画像成功，无 SQL 报错

### Bug 2: predictedTotal.toFixed is not a function
- **现象**：点击餐费分析 Tab 报 TypeError，页面无法渲染
- **根因**：API 返回值可能是字符串或 undefined，直接调用 `toFixed` 报错
- **修复**：添加 `toNum/formatMoney/formatInt` 安全格式化函数，替换模板中所有 `.toFixed()` 调用
- **验证**：控制台无红错，Tab 正常切换

### Bug 3: 空字符串覆盖已有昵称
- **现象**：信息设置保存空昵称时，覆盖了已有昵称
- **根因**：`updateProfile` 只判断 `!= null`，空串 `""` 仍会更新
- **修复**：增加 `!dto.getField().trim().isEmpty()` 判断
- **验证**：空昵称不再覆盖已有值

### Bug 4: 柱状图不显示
- **现象**：消费趋势只有日期标签，无柱状图
- **根因**：`.bar` CSS 无 `min-height`，数据为0时不可见
- **修复**：添加 `min-height: 20rpx`，填充默认数据避免空白
- **验证**：柱状图始终可见

# ECC 重构与性能优化速查卡

## 一键 Prompt（10 条）

```text
对 {模块} 做行为不变重构，目标是降低复杂度并提升可测试性。
```

```text
请先做重构计划：痛点、改造顺序、风险、验证方法，再开始改代码。
```

```text
请把 {函数/类} 拆分成更小单元，并补上关键测试。
```

```text
对 {慢接口} 做性能诊断：定位瓶颈、给量化数据、给优化方案。
```

```text
请对 {SQL} 做优化建议，并说明索引/执行计划变化预期。
```

```text
请优化 {页面} 首屏性能并给前后对比指标。
```

```text
请优先处理“低风险高收益”的性能优化项，给执行清单。
```

```text
在保持外部接口不变前提下，重构 {模块} 内部结构。
```

```text
请输出重构后的回归测试清单，确保无行为变化。
```

```text
请给这次优化的收益评估：响应时间、资源消耗、可维护性提升。
```

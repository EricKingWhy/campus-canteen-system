# 开发日志 2026-01-23

## 📋 今日工作概述

今天完成了两大核心模块的修复：**收藏功能全链路修复** 和 **管理后台全量审计与修复**。

## ❤️ 1. 收藏功能全链路修复

### 问题描述
- 用户点击收藏后，切换菜品再回来，红心状态丢失
- "我的收藏"页面显示空白
- "再来一单"功能无效

### 根因分析
1. **后端 `Favorite` 实体**：包含数据库不存在的 `setmealId` 字段，导致 SQL 查询报错
2. **后端 `ShoppingCartService`**：方法体为空，添加购物车无实际逻辑
3. **前端 `DishDetailPopup.vue`**：仅在 `visible` 变化时检查收藏状态，切换菜品时不更新

### 修复内容

| 文件 | 修改内容 |
|------|----------|
| `Favorite.java` | 移除 `setmealId` 字段 |
| `ShoppingCartServiceImpl.java` | 实现完整的 `add`/`list`/`clean` 方法 |
| `DishDetailPopup.vue` | 使用 `deep watch` 同时监听 `visible` 和 `dish` 变化 |
| `favorite.vue` | 新增"再来一单"按钮，调用 `addToCartAPI` |

## 🖥️ 2. 管理后台全量审计与修复

### 问题描述
- Dashboard 今日数据/订单信息等卡片显示空白
- 数据统计页面图表不显示任何数据
- 需隐藏"套餐管理"、"待派送"、"新增用户"等校园食堂不需要的功能入口

### 根因分析
1. **`WorkspaceServiceImpl`**：所有方法返回空 VO 对象
2. **`ReportServiceImpl`**：所有统计方法返回空 VO 对象
3. 套餐相关 UI 入口未隐藏

### 修复内容

#### A. UI 入口隐藏

| 隐藏项 | 文件 | 处理方式 |
|--------|------|----------|
| 套餐管理菜单 | `layout/index.vue` L37-42 | HTML 注释 |
| 套餐总览卡片 | `dashboard/index.vue` L13-15 | HTML 注释 |
| 新增用户卡片 | `overview.vue` L32-35 | HTML 注释 |
| 待派送卡片 | `orderview.vue` L25-35 | HTML 注释 |
| 待派送 Tab | `orderList.vue` L299 | JS 注释 |

#### B. 后端服务实现

**WorkspaceServiceImpl.java** - Dashboard 数据
- `getBusinessData()`: 计算今日营业额、有效订单、完成率、客单价
- `getOverviewOrders()`: 统计各状态订单数量
- `getOverviewDishes()`: 统计启售/停售菜品数
- `getOverviewSetmeals()`: 统计启售/停售套餐数

**ReportServiceImpl.java** - 数据统计页
- `getTurnover()`: 按日期查询已完成订单营业额，返回逗号分隔字符串
- `getUser()`: 按日期统计总用户/新增用户
- `getOrder()`: 按日期统计订单总数/有效订单/完成率
- `getSalesTop10()`: 从订单详情表统计销量 Top10 菜品
